## 서비스에 맞게 작성한 디자인 브리프

한국어 개인용 할 일 앱을 설계한다. 248px 내외의 옅은 회색 사이드바와 흰색 작업 공간을 사용한다. 본문은 읽기 쉬운 산세리프, 기본 14px, 제목 28px로 두고 내용은 왼쪽 정렬한다. 하나의 짙은 주황색을 선택 상태와 주요 행동에만 사용한다. 할 일은 카드보다 행으로 표시하고 얇은 구분선으로 정리한다. 기한과 프로젝트는 작은 보조 정보로 표시한다. 상세 편집은 오른쪽 패널에서 제공한다. 휴대폰에서는 탐색 메뉴를 접고 44px 이상의 터치 영역을 확보한다. 빈 목록, 저장 중, 실패, 삭제 후 복구 상태를 완성한다. 키보드로 전체 작업을 수행할 수 있게 한다.

## 판단

Swiss 원문에 제안된 거대한 제목과 굵은 테두리는 반복 사용 도구의 밀도에 맞지 않아 채택하지 않았다. Professional의 절제된 간격은 참고하되 한국어 본문에는 산세리프를 사용한다. 화면의 주인공은 사용자가 입력한 할 일이다. 그림, 광고성 문구, 장식적 통계 대신 목록과 편집 흐름에 집중한다.

## 사용 흐름

체험하기 또는 가입 → 오늘 목록 → 할 일 추가 → 기한과 프로젝트, 우선순위 지정 → 완료 → 완료 기록. 삭제는 휴지통으로 이동하고 복원할 수 있다. 체험 데이터는 별도 계정에 저장되고 가입하면 자신의 계정으로 전환된다.
