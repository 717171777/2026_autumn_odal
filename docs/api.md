# API

모든 사용자 데이터는 로그인 세션에 해당하는 계정만 접근할 수 있습니다. 변경 요청에는 현재 사이트와 동일한 Origin 헤더가 필요합니다. 응답은 캐시하지 않습니다.

| 메서드 | 경로                | 내용                                                                   |
| ------ | ------------------- | ---------------------------------------------------------------------- |
| POST   | `/api/auth/signup`  | 이름, 이메일, 비밀번호로 가입. 체험 계정은 기존 데이터를 유지하며 전환 |
| POST   | `/api/auth/login`   | 로그인                                                                 |
| POST   | `/api/auth/logout`  | 세션 폐기                                                              |
| POST   | `/api/auth/demo`    | 독립된 체험 계정 생성                                                  |
| GET    | `/api/workspace`    | 사용자 정보, 프로젝트, 할 일, 사용자 시간대의 오늘 날짜                |
| POST   | `/api/tasks`        | 할 일 생성                                                             |
| PATCH  | `/api/tasks/:id`    | 할 일 전체 내용 수정 또는 상태 변경                                    |
| POST   | `/api/projects`     | 프로젝트 생성                                                          |
| PATCH  | `/api/projects/:id` | 이름과 색상 수정 또는 보관과 복원                                      |
| PATCH  | `/api/settings`     | 이름과 시간대 수정                                                     |
| GET    | `/api/health`       | 데이터베이스 연결 확인                                                 |

## 할 일 내용

```json
{
  "title": "강의 노트 정리",
  "notes": "3주차 내용",
  "project_id": null,
  "due_date": "2026-10-03",
  "priority": 1,
  "recurrence": "none",
  "checklist": []
}
```

우선순위는 0 보통, 1 높음, 2 중간, 3 낮음입니다. 반복은 `none`, `daily`, `weekly`, `monthly` 중 하나입니다. 반복에는 기한이 필요합니다. 체크리스트 항목은 UUID인 `id`, `title`, `done`을 가집니다.

상태 변경은 `{"action":"complete"}`, `{"action":"reopen"}`, `{"action":"trash"}`, `{"action":"restore"}` 중 하나입니다. 프로젝트는 `archive`, `restore`를 사용합니다.

반복 완료는 다음 날짜의 할 일을 생성합니다. 매월 31일과 같은 일정은 다음 달의 마지막 날로 맞춥니다. 완료를 취소하면 수정되지 않은 다음 반복 할 일도 제거합니다. 다음 할 일이 이미 수정됐거나 완료됐다면 409를 반환해 기록이 사라지는 것을 막습니다.

## 응답

400은 잘못된 입력, 401은 로그인 필요, 403은 다른 Origin, 404는 접근할 수 없는 항목, 409는 상태 충돌, 429는 로그인 시도 제한, 503은 연결 오류입니다. 오류 응답은 `{"error":"안내 문구"}` 형태입니다.

비밀번호는 scrypt로 저장합니다. 세션 원문은 HttpOnly 쿠키에만 두고 데이터베이스에는 SHA-256 해시를 저장합니다. 운영 환경에서는 Secure 쿠키를 사용합니다. 로그인과 가입 시도 제한은 PostgreSQL에 기록되므로 서버 인스턴스 사이에서도 유지됩니다.
